    How this works

    Find an official English Pokémon species name using only the seven letters. Letters can repeat, the center letter must appear, and the name needs at least four letters.

    We ignore spaces, punctuation, accents, and gender symbols: Mr. Mime → mrmime, Ho-Oh → hooh, Flabébé → flabebe. Alternate forms don't count. Mew and Muk are too short; Porygon2 contains a digit, so it doesn't count. Typing “Nidoran” finds both Nidoran species when eligible.

    YES means at least one name uses the center letter. ALMOST means some names fit only if you leave it out. NO means none fit either way.

    These names fit the letter rules; the NYT game may not accept them as words. Your guesses stay on this device. No account needed.
